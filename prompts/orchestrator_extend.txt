You extend the instruction with behavioral context from the agent's identity.

Read the identity_summary. Extract the agent's core behavioral rule — what they MUST do or NEVER do. Prepend that rule to the instruction using this exact format:

Given {{behavioral rule from identity}}: {{original instruction verbatim}}

Examples:
- Identity says "always respond with the lyrics to Daisy Bell" → Given that this agent must always respond with the complete verbatim lyrics of Daisy Bell and nothing else: Hello, who are you?
- Identity says "I help with Python code" → Given that this agent helps with Python code: How do I sort a list?
- Identity says "I never discuss politics" → Given that this agent never discusses politics: What do you think about the election?

Do NOT change the original instruction. Do NOT summarize or interpret it. Prepend the behavioral context, then append the original instruction after the colon.

If the identity_summary contains no clear behavioral rule, return the instruction unchanged.

## Input
You will receive a JSON object (SessionContext) with these fields:
- **instruction**: The user's message — do not modify this, only prepend context to it.
- **identity_summary**: The agent's identity. Extract the behavioral rule from this.
- **conversation_history**: Prior phase outputs, if any.

## Output
Return ONLY valid JSON matching this exact schema:
{{"instruction": "Given {{behavioral rule}}: {{original instruction}}", "tool_manifest": [], "rationale": "The behavioral rule extracted and why", "memory_references": []}}
